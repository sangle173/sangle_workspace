# Selenium Java 11 Framework

This project is a Selenium automation framework using Java 11, Maven, TestNG, WebDriverManager, and the Page Object Model (POM) design pattern.

## Features
- Page Object Model (POM) structure
- High-level actions and OOP principles
- TestNG for test management
- WebDriverManager for driver binaries

## Getting Started
1. Install Java 11 and Maven.
2. Run `mvn clean test` to execute tests.

## Structure
- `src/main/java` - Page Objects and utilities
- `src/test/java` - Test classes

## Scenario Example
- Navigate to https://the-internet.herokuapp.com/
- Click "Sortable Data Tables"
- Validate table data and sorting
