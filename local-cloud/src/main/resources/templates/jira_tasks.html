Environment Setup Instructions
  1. Create a file named .env in the folder ~/Desktop/Env/
  2. Add your Jira API token to the file in this format: JIRA_API_TOKEN=your_token_here
  3. Make sure the jira_filter.json file exists in the same folder
  4. Save the file and restart the application
