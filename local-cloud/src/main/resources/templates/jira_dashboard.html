Your Tasks
  1. Create a file named .env in the folder ~/Desktop/Env/
  2. Add your Jira API token to the file in this format: JIRA_API_TOKEN=your_token_here
  3. Save the file and restart the application
You can get a Jira API token by visiting your Jira account settings.
How to Use the JIRA Dashboard
  1. Enter your JIRA issue keys in the textarea (one per line or separated by space)
  2. Click the "Fetch Issues" button to retrieve the issues
  3. View the issues in the table or in Slack format
  4. Use the tabs to switch between views
  5. Click on "Your Tasks" to access pre-defined JIRA filters

Note: JIRA filters are defined in ~/Desktop/Env/jira_filter.json

Note: To use this feature, you need to set up your Jira API token in the ~/Desktop/Env/.env file with the key JIRA_API_TOKEN. Example: JIRA_API_TOKEN=your_actual_token_here
