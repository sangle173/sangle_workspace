How to Use the Video Cutter
  1. Select a video from the dropdown menu
  2. Preview the video using the player below the form
  3. Set the start and end times for your cut (format: HH:MM:SS)
    • Use the "Set Current Time" button to automatically set the start time to the current playback position
  4. Choose whether to use precise cutting (slower but more accurate)
  5. Click "Cut Video" to process your request
  6. Once complete, you can preview and download the cut video
